القسم 01

الملخّص التنفيذي

BSN (شريك الأعمال) وكالة رقمية مصرية متخصصة في 4 خدمات (مواقع، متاجر، هوية، تسويق) مع +40 مشروع و12 سنة خبرة. الهدف هو تحويل الموقع الحالي من brochure-site لمنصّة تشغيلية كاملة.

01

الفرصة السوقية

السوق العربي للـ freelance نما 385% منذ 2020 ووصل لـ $1.4 مليار في 2025. مفيش وكالة عربية حالياً تعمل productized self-service بشكل احترافي كامل — كلهم إما تقليديين أو marketplaces.

02

الـ Positioning

BSN في منطقة فريدة: وكالة متخصصة + سهولة طلب الـ marketplace. فريق واحد مسؤول، أسعار شفافة، portal كامل، وتجربة عربية أصيلة — vs Khamsat (جودة متفاوتة) و الوكالات التقليدية (بطيئة وغير شفافة).

03

التحوّل المقترح

إضافة Order Flow + Quote Workflow فوق البنية الموجودة (Auth، Projects، Payments، Chat، Packages CMS) — مع Multi-step wizard، add-ons، coupons، bundles، وOnboarding.

✓
الوضع الحالي: الـ MVP موجود وشغّال (Laravel 11 + React 18 + Reverb + 5 بوابات دفع + 3 dashboards + Audit Logs + PWA + Docker + CI). تقدير 95% production-ready من الناحية التقنية، بس ناقص الـ business workflow الأساسي للتحوّل لمنصّة.

القسم 02

الرؤية والتحوّل

الوضع الحالي · "الوكالة"

  • الموقع brochure: بيعرض الخدمات والأعمال
  • التواصل عبر WhatsApp/Email/Phone
  • عرض السعر بياخد 3-7 أيام بعد الاجتماعات
  • العميل ما يعرفش حالة المشروع إلا لما يسأل
  • الدفع بتحويل بنكي أو nقدي
  • الملفات والمستندات scattered على WhatsApp/Email
⚠
المشكلة: نموذج بطيء، غير قابل للتوسّع، ومتعب لكل من الفريق والعميل.

الوضع المستهدف · "المنصّة"

  • المنصة productized: العميل يختار باقة ويدفع مباشرة
  • portal كامل: chat real-time، tracking، deliverables
  • قرارات في 24 ساعة (custom)، 0 ثانية (packages)
  • كل التواصل والملفات داخل المنصة
  • دفع إلكتروني بـ 5 بوابات + الـ wallets المحلية
  • إشعارات تلقائية لكل marker مهم
✓
الحل: منصّة قابلة للتوسّع، شفافة، وراحة للطرفين.

التحوّل في 3 محاور

1. تحوّل الطلبات

من email/WhatsApp → form دائري متعدد المراحل بـ Wizard ذكي + Path A (packages) و Path B (custom quote).

2. تحوّل التشغيل

من spreadsheets → admin dashboard كامل لإدارة الـ leads، quotes، orders، packages، coupons، bundles.

3. تحوّل الإيرادات

من one-time projects → mix من packages، subscriptions (للتسويق)، bundles بخصومات، وupsells.
